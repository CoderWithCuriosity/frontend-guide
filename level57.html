Simple Form Validation

Before you submit or process a form, you should check that required fields aren't empty. The core check is simple: if (input.value === ""). When a field is empty, show an error message and stop the action.

Key Takeaways

  • input.value === "" — the basic empty check.
  • value.trim() — removes whitespace so "   " is treated as empty.
  • Return early — if the field is empty, stop the action with return;.
  • Show error text — toggle a CSS class like .show to display the message.
  • Reset the error — clear the error when the field becomes valid.
  • One field at a time — validate each required field in order.
