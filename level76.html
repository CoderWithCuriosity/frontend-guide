What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework. Instead of writing your own CSS rules, you add small ready-made classes right in your HTML. Each class does one job. 

<!-- Normal CSS: write a .btn rule in a stylesheet -->
<button class="btn">Save</button>

<!-- Tailwind: the classes ARE the styles -->
<button class="bg-blue-500 text-white px-4 py-2 rounded-lg hover:bg-blue-700">
    Save
</button>

Add it to a page

The quickest way for practice is the Play CDN — one script tag in your <head>:

<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
