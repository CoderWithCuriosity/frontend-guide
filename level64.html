Simple Arrow Functions

Arrow functions are a shorter way to write functions. Compare the traditional syntax with the modern arrow syntax below.

Traditional
Classic syntax
function add(a,b) {
return a+b;
}
Arrow (Block)
With braces & return
const add = (a,b) => {
return a+b;
}
Arrow (Implicit)
No braces, no return
const add = (a,b) => a+b;

Key Takeaways

  • const myFunc = () => {} — the arrow syntax.
  • Single param — parentheses optional: x => x * 2.
  • Implicit return — omit braces and return for one expression.
  • Multiple statements — use braces {} and explicit return.
  • No own this — arrow functions inherit this from the surrounding scope.
  • Common use — callbacks for map, filter, reduce, and event listeners.
