LocalStorage with Objects (JSON)

localStorage only stores strings. To save an object or array, convert it to a JSON string with JSON.stringify(). To read it back, use JSON.parse() to turn the string into an object again.

Console Output

// Save an object to localStorage
> let user = { name: "Alice", age: 25, city: "Portland" };
> localStorage.setItem("user", JSON.stringify(user));

// Read it back
> let stored = JSON.parse(localStorage.getItem("user"));
> console.log(stored.name);
"Alice"

// Save an array of objects
> let users = [{ name: "Alice" }, { name: "Bob" }];
> localStorage.setItem("users", JSON.stringify(users));
> console.log(JSON.parse(localStorage.getItem("users")).length);
2

Key Takeaways

  • JSON.stringify(obj) — converts an object to a string.
  • JSON.parse(str) — converts a JSON string back to an object.
  • localStorage — only stores strings, so JSON is required for objects.
  • Save pattern — setItem(key, JSON.stringify(obj)).
  • Load pattern — JSON.parse(getItem(key)).
  • Missing key — getItem returns null, so guard before parsing.
