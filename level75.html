Page structure

TagWhat it does
<!DOCTYPE html>Tells the browser this is an HTML5 page. Always the first line.
<html>Wraps the whole page.
<head>Info about the page: title, CSS links, meta tags.
<title>Text shown on the browser tab.
<meta name="viewport">Makes the page fit phone screens (responsive design).
<body>Everything you can see on the page.

Text

TagWhat it does
<h1> – <h6>Headings. h1 is the biggest and most important.
<p>A paragraph.
<strong> / <b>Bold text (strong also means "important").
<em> / <i>Italic text (em also means "emphasis").
<u> / <mark>Underlined / highlighted text.
<br>Line break (no closing tag).
<hr>A horizontal line.

Lists, links & images

TagWhat it does
<ul>Unordered list (bullets).
<ol>Ordered list (1, 2, 3).
<li>One item inside a list.
<a href="">A link. href is where it goes. target="_blank" opens a new tab.
<img src="" alt="">An image. alt describes it if it can't load.

Layout & forms

TagWhat it does
<div>A block box for grouping things.
<span>An inline box for a small piece of text.
<header> / <nav> / <footer>Top section / navigation links / bottom section.
<form>Wraps inputs that get submitted.
<label for="id">Text for an input. for matches the input's id.
<input>A field. type can be text, email, password, checkbox...
<textarea>A big box for many lines of text.
<button>A clickable button.
