Text Content Switcher

In this project you'll change the text inside an element using element.textContent. A small state variable keeps track of what's currently shown so you can update it with buttons.

Console Output

// Change text content directly
> let heading = document.getElementById("mainText");
> heading.textContent = "New text here";

// Track state with a variable
> let currentIndex = 0;
> const messages = ["One", "Two", "Three"];
> heading.textContent = messages[currentIndex];
"One"

// Cycle to the next message
> currentIndex = (currentIndex + 1) % messages.length;
> heading.textContent = messages[currentIndex];
"Two"

Key Takeaways

  • element.textContent — replaces the text inside an element.
  • State variable — store the current index in a variable.
  • Modulo (%) — wrap around the array: (i + 1) % arr.length.
  • Button clicks — use onclick or addEventListener.
  • Array of messages — a simple way to store multiple texts.
  • Immediate feedback — the page updates the instant you click.
