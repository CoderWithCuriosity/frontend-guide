GET vs POST

In Level 70 you used a GET request to get data from a server. A POST request does the opposite: it sends new data to the server, like when you sign up, post a comment or submit a form.

MethodWhat it doesExample
GETGet data from the serverLoad a list of posts
POSTSend new data to the serverCreate a new post

Writing a POST request

For a POST you give fetch() a second argument: an object with 3 things.

  1. method — set it to "POST".
  2. headers — tell the server you are sending JSON.
  3. body — the data, turned into text with JSON.stringify().
let newPost = {
    title: "My first post",
    body: "Hello world!",
    userId: 1
};

fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: {
        "Content-Type": "application/json"
    },
    body: JSON.stringify(newPost)
})
    .then(response => response.json())
    .then(data => {
        console.log(data); // the server sends back the post with a new id
    })
    .catch(error => {
        console.log("Something went wrong");
    });

Key Takeaways

  • POST sends new data to the server.
  • method: "POST" — without it, fetch sends a GET.
  • headers — "Content-Type": "application/json" says the body is JSON.
  • body must be text, so use JSON.stringify(object).
  • Status 201 means "Created" — the server made your new item.
  • JSONPlaceholder is fake: it replies like a real server (new id: 101) but does not really save your post.
