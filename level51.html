Array CRUD · Reading & Adding

Arrays store ordered collections. You can read any element using its index (starting at 0), and you can add new items by assigning a value to a new index or using .push().

> fruits[3] = "date";
> console.log(fruits);
["apple", "banana", "cherry", "date"]

// Using .length to append
> fruits[fruits.length] = "elderberry";
> console.log(fruits.length);
5

Key Takeaways

  • arr[index] — reads the element at that position (0‑based).
  • arr[index] = value — writes/overwrites the element at that index.
  • arr[arr.length] = value — appends a new element at the end.
  • .length — returns the number of elements in the array.
  • .push(value) — adds one or more elements to the end.
  • Reading a non‑existent index returns undefined.
