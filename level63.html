Template Literals: Clean HTML Generation

Template literals let you build HTML strings with embedded variables using backticks and ${...}. Instead of concatenating with +, you write the markup naturally and inject values where needed.

Console Output

// Old way — messy string concatenation
> let html = "<div>" +
> "<h2>" + name + "</h2>" +
> "<p>Age: " + age + "</p>" +
> "</div>";

// New way — clean template literal
> let html = `
> <div class="user-card">
> <h2>${name}</h2>
> <p>Age: ${age}</p>
> <p>City: ${city}</p>
> </div>
> `;

// Render into the page
> document.getElementById("app").innerHTML = html;

Key Takeaways

  • Backticks (`) — wrap the template, not quotes.
  • ${expression} — inject any variable or expression.
  • Multi-line — write HTML across lines naturally.
  • Readable — no more concatenation with +.
  • innerHTML — set to the template string to render it.
  • .map().join("") — build lists from arrays inside templates.
