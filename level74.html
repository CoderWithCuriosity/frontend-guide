Icons with Remix Icon

Remix Icon is a free set of 3,000+ icons. Each icon is a character in a special font, so you style it just like text — with font-size and color. You load it from a CDN (a link to a file on the internet), so there is nothing to download.

How to use it

  1. Add the CDN link inside your <head>.
  2. Add an icon with an <i> tag and the icon's class name, like ri-home-line.
  3. Style it with font-size to change the size and color to change the color.
<head>
    <link href="https://cdn.jsdelivr.net/npm/remixicon@4.5.0/fonts/remixicon.css"
          rel="stylesheet">
</head>

<body>
    <i class="ri-home-line"></i>     <!-- outline -->
    <i class="ri-home-fill"></i>     <!-- filled  -->

    <button>
        <i class="ri-download-line"></i> Download
    </button>
</body>

Change an icon with JavaScript

Icons are just classes, so you can swap them with classList. Click the heart:

12 likes 
likeBtn.addEventListener("click", () => {
    likeIcon.classList.toggle("ri-heart-line");
    likeIcon.classList.toggle("ri-heart-fill");
});

Key Takeaways

  • Find icons: remixicon.com — click any icon to copy its class name.
  • Every class starts with ri- and most end with -line or -fill.
  • Decoration only? Add aria-hidden="true" so screen readers skip it.
  • Icon-only button? Add aria-label so people know what it does.
