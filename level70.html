What is fetch()?

fetch() is a built-in JavaScript function that asks a server for data. Many websites share data through an API — a URL that returns data (usually JSON) instead of a web page.

Asking for data is called a GET request. In this level we use JSONPlaceholder, a free fake API made for practice. It needs no sign-up and no API key.

The 3 steps of a GET request

  1. Send the request with fetch(url).
  2. Turn the reply into data with response.json().
  3. Use the data in the next .then() — show it on the page.
fetch("https://jsonplaceholder.typicode.com/posts/1")
    .then(response => response.json())
    .then(data => {
        console.log(data.title);
    })
    .catch(error => {
        console.log("Something went wrong");
    });

The .catch() at the end runs only if something goes wrong, for example when there is no internet.

Key Takeaways

  • fetch(url) sends a GET request by default.
  • response.json() turns the reply into a JavaScript object.
  • .then() runs when the data is ready.
  • .catch() runs when something goes wrong.
  • Practice API: https://jsonplaceholder.typicode.com
