How It Works

// 1. Read input value
> const text = document.getElementById("itemInput").value.trim();

// 2. Push to array
> items.push({ id: Date.now(), text: text });

// 3. Save to localStorage
> localStorage.setItem("level65_items", JSON.stringify(items));

// 4. Delete an item by id
> items = items.filter(item => item.id !== id);
> save(); render();

// 5. Load on page start
> items = JSON.parse(localStorage.getItem("level65_items")) || [];

Key Takeaways

  • Input value — read with .value.trim().
  • Array CRUD — .push() to add, .filter() or .splice() to remove.
  • localStorage + JSON — stringify to save, parse to load.
  • Render loop — rebuild the list from the array on every change.
  • Unique IDs — Date.now() gives each item a unique key.
  • Empty-state — show a friendly message when the list is empty.
