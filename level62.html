// Typical countdown pattern
> let count = 10;
> let id = setInterval(() => {
> count--;
> if (count === 0) clearInterval(id);
> }, 1000);

Key Takeaways

  • setInterval(fn, ms) — runs fn every ms milliseconds.
  • clearInterval(id) — stops the interval using its ID.
  • Store the ID — you must keep the return value of setInterval().
  • 1000 ms = 1 second — the standard delay for tick-based timers.
  • Guard the decrement — check if the count reached 0 before stopping.
  • Reset — clear the interval and reset the count to the starting value.
