What is a modal?

A modal is a small window that pops up on top of the page. The page behind it gets a dark see-through overlay, so the user focuses on the popup. You see them for login boxes, "Are you sure?" messages and newsletter sign-ups.

1. The HTML

One overlay with the modal box inside. It is hidden until we add the open class.

<button id="openBtn">Open Modal</button>

<div class="modal-overlay" id="overlay">
    <div class="modal">
        <button class="modal-close" id="closeBtn">&times;</button>
        <h3>Hello!</h3>
        <p>This is a modal popup.</p>
    </div>
</div>

2. The CSS

.modal-overlay {
    position: fixed;          /* cover the whole screen */
    inset: 0;                 /* top, right, bottom, left = 0 */
    background: rgba(0, 0, 0, 0.6);
    display: flex;
    justify-content: center;
    align-items: center;
    opacity: 0;
    visibility: hidden;       /* hidden by default */
    transition: 0.25s;
    z-index: 1000;            /* sit on top of everything */
}

.modal-overlay.open {
    opacity: 1;
    visibility: visible;
}

3. The JavaScript

const overlay = document.getElementById("overlay");

function openModal() {
    overlay.classList.add("open");
}

function closeModal() {
    overlay.classList.remove("open");
}

openBtn.addEventListener("click", openModal);
closeBtn.addEventListener("click", closeModal);

// Click on the dark area (not the box) closes it
overlay.addEventListener("click", (e) => {
    if (e.target === overlay) closeModal();
});

// Escape key closes it
document.addEventListener("keydown", (e) => {
    if (e.key === "Escape") closeModal();
});

Key Takeaways

  • The X button — always give users a clear way out.
  • Clicking the overlay — check e.target === overlay so clicks inside the box don't close it.
  • The Escape key — listen for e.key === "Escape".
  • Stop page scroll — set document.body.style.overflow = "hidden" while open.
