Array of Objects · Structure & Access

An array of objects is the most common way to store list data in JavaScript. Each element in the array is an object, and you can access fields with list[index].property.

list[0]
name: "Alice"
age: 28
role: "Developer"
list[1]
name: "Bob"
age: 34
role: "Designer"
list[2]
name: "Carol"
age: 25
role: "Manager"

Console Output

// Creating an array of objects
> let users = [
> { name: "Alice", age: 28, role: "Developer" },
> { name: "Bob", age: 34, role: "Designer" },
> { name: "Carol", age: 25, role: "Manager" }
> ];

// Accessing a single item
> console.log(users[0].name);
"Alice"
> console.log(users[2].role);
"Manager"

// Looping through the array
> users.forEach(u => console.log(u.name));
"Alice"
"Bob"
"Carol"

Key Takeaways

  • list[index] — gets a single object from the array.
  • list[index].property — gets a field from that object.
  • list.length — number of objects in the array.
  • forEach / for…of — loop through every object in the list.
  • Objects in the array can have different shapes, but usually share the same keys.
  • Bracket notation also works: list[0]["name"].
