Object CRUD · Creating & Reading

Objects store data as key-value pairs. You can read any property using dot notation (obj.key) or bracket notation (obj["key"]). Both are essential for working with object data.

Console Output

// Creating an object
> let person = { name: "Alice", age: 28, city: "Portland" };

// Dot notation
> console.log(person.name);
"Alice"
> console.log(person.age);
28

// Bracket notation
> console.log(person["city"]);
"Portland"
> let prop = "name";
> console.log(person[prop]);
"Alice"

// Adding a new property
> person.email = "alice@example.com";
> console.log(person.email);
"alice@example.com"

Key Takeaways

  • obj.key — dot notation reads a property by its literal name.
  • obj["key"] — bracket notation reads a property using a string.
  • obj[var] — bracket notation lets you use a variable as the key.
  • obj.newKey = value — adds a new property or updates an existing one.
  • Reading a missing property returns undefined.
  • Use brackets when the key has spaces or comes from a variable.
